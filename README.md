# Визуализатор графа зависимостей (Cargo / Rust)

## 1. Общее описание
Инструмент командной строки для построения и визуализации графа зависимостей пакетов менеджера Cargo (Rust). Анализ производится с помощью обхода в глубину (DFS) без использования рекурсии. Поддерживается вывод порядка загрузки и построение графа в формате Graphviz.

## 2. Описание функций и настроек
Настройки передаются через аргументы командной строки:
* `--pkg` — Имя анализируемого пакета.
* `--url` — URL репозитория или путь к тестовому файлу.
* `--test` — Флаг включения тестового режима (чтение из файла).
* `--ver` — Версия анализируемого пакета.
* `--out` — Имя генерируемого файла с графом (формат PNG).
* `--ascii` — Вывод дерева зависимостей в формате ASCII.

## 3. Команды для сборки и запуска тестов
Для работы генерации изображений требуется установленный в системе `Graphviz` (утилита `dot`).
Сборка не требуется (чистый Python).
Запуск:
```bash
bash run.sh --pkg libc --ver 0.2.147 --url "[https://crates.io](https://crates.io)" --out result.png
